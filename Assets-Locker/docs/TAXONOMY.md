# Resource Taxonomy

## Design & Visual Assets

| Category | Includes | Typical use |
|---|---|---|
| Design Inspiration | Websites, product screens, layout references | Visual direction and UX study |
| Icons & Logos | Icon sets, brand marks, SVG collections | Interface iconography |
| Illustrations | Vector scenes, characters, editorial artwork | Explanatory or decorative visuals |
| Photos & Mockups | Photography, device frames, product mockups | Media and presentation |
| Backgrounds & Patterns | Gradients, SVG patterns, textures | Surface decoration |
| Typography & Colors | Font libraries, pairing and palette tools | Type and color tokens |
| Animation & 3D | Motion libraries, Lottie, 3D assets and tools | Motion and spatial visuals |

## UI & Design Systems

| Category | Includes | Typical use |
|---|---|---|
| UI Component Libraries | Components and interaction primitives | Reusable UI |
| Design Systems | Tokens, guidelines, components, standards | Consistent product language |
| Responsive Patterns | Adaptive layouts and navigation | Multi-device behavior |
| Forms & UI States | Validation, loading, empty, error, success | Complete interaction flows |
| Data Visualization | Charts, tables, dashboards, visual encoding | Data communication |

- React & TypeScript

## Tag conventions

Use lowercase kebab-case tags such as `react`, `vite`, `tailwind`, `dashboard`, `saas`, `accessibility`, `free-tier`, and `license-review`.

Do not create a new category for a single resource unless it represents a recurring retrieval need.
